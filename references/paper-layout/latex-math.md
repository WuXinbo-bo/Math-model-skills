# LaTeX 数学表达合同

## 语义顺序

核心公式按“动机或机制说明 -> 原生公式 -> 编号 -> 符号/单位/定义域 -> 公式作用或推论”组织。禁止连续堆放公式后再统一解释，也禁止用公式截图代替可编辑数学环境。

## 环境选择

- 单行且需要引用：`equation`。
- 多行同一推导：`align` 或 `aligned`，优先在等号、不等号或主要运算符处对齐。
- 一个语义公式只保留一个主编号；需要逐行引用时才逐行编号。
- 无需引用的短式可用 `\[...\]`，但模型定义、目标函数和关键约束应使用可引用环境。
- 禁止用 `\resizebox` 压缩公式。长公式应拆分、引入中间变量或改写为分段/集合形式。

## 书写规范

- 公式是句子的一部分，按中文语义添加逗号或句号。
- 变量使用数学斜体，函数名、单位、算子和说明性下标使用正体。
- 数值与单位之间保留不可断空格，单位写法全文一致。
- 每个新符号首次出现时定义；同一符号不得跨章节改变含义。
- 目标函数、约束两边和可相加项必须量纲一致；无量纲化需说明基准量。
- 正文引用一律使用 `\eqref`、`\ref` 或 `\cref`，禁止手写“式（7）”“图 5”“表 3”。

## 公式密集页

公式之间必须保留必要解释，但不以大段算法教材内容填充。页面至少形成一次“机制 -> 公式 -> 解释/结果”的闭环；若连续公式超过三组，优先增加小结、定义中间量或拆分小节。

## 发布门禁

- 编译日志不存在 Overfull/Undefined reference。
- 没有以 `formula_*`、`equation_*` 等图片替代正文公式。
- 核心编号公式至少在后文被引用或解释一次。
- 手写图、表、公式编号必须改为语义交叉引用。
